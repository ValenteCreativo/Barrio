# Cliente Android (siguiente etapa)

Esta carpeta reserva el lugar del cliente nativo de BARRIO. La base actual contiene la landing y la demo web; aún no se creó un proyecto Android ni se conectó ningún servicio.

## Stack propuesto

- Kotlin para el lenguaje de la app.
- Jetpack Compose para construir la interfaz Android.
- Estado local/mock mientras se define e integra la API.

La app podrá reutilizar los flujos visuales de `../prototype/` como referencia. El repositorio no incluye base de datos ni credenciales.
